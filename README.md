# DateSpark 💑 – Приложение для планирования свиданий

**DateSpark** – это полнофункциональное веб-приложение для пар, которое помогает находить, планировать и отслеживать идеи для свиданий через интуитивный Tinder-подобный интерфейс и совместную канбан-доску.

> 🌐 **Живое приложение:** [https://datespark-frontend.onrender.com](https://datespark-frontend.onrender.com)
> 
## 👤 Тестовый доступ

Для быстрого ознакомления с функционалом можно использовать тестовый аккаунт:

- **Email:** `test@example.com`
- **Пароль:** `12345`

Или зарегистрируйте нового пользователя и создайте пару для полноценного тестирования.
Используются бесплатные тарифы Render/Supabase, поэтому при первом обращении после периода бездействия сервисам требуется подождать 1 - 2 минуты на пробуждение.

## 🎯 Основные возможности

### 🔐 **Аутентификация и пары**
- Регистрация и вход с JWT-токенами
- Создание пары с уникальным кодом приглашения
- Присоединение к существующей паре
- Управление профилем пользователя и пары

### 💡 **Генератор идей (Tinder-режим)**
- Свайп карточек: вправо ❤️ (нравится) / влево 💔 (не нравится)
- Умные фильтры: категория, настроение, бюджет ($/$$/$$$), локация, погода
- Автоматическое добавление лайкнутых идей на доску приключений
- Полноценная поддержка тач-жестов и мыши

### 📋 **Доска приключений (Adventure Board)**
- Синхронизированная канбан-доска для пары
- 4 колонки статусов:
  - 💡 **Лайкнутые** – понравившиеся идеи
  - 📅 **Запланированные** – готовые к реализации
  - 🚀 **В процессе** – активные свидания
  - ✅ **Выполненные** – завершённые приключения
- Ручное добавление идей
- Управление статусами и удаление карточек

## 🛠️ Технологический стек

### **Backend (ASP.NET Core 8.0)**
- **Framework:** ASP.NET Core 8.0 + Entity Framework Core
- **База данных:** PostgreSQL (развёрнута на Supabase)
- **Аутентификация:** JWT + BCrypt для хеширования паролей
- **Контейнеризация:** Docker
- **Миграции:** Автоматические миграции EF Core с seed-данными
- **Документация:** Swagger/OpenAPI
- **Деплой:** Render.com

### **Frontend (React 19 + TypeScript)**
- **Фреймворк:** React 19 + TypeScript
- **Роутинг:** React Router 7
- **Стили:** CSS Modules
- **Типизация:** Полная TypeScript типизация
- **PWA:** Progressive Web App
- **UI/UX:** Адаптивный дизайн + мобильная навигация
- **Деплой:** Render.com (статический хостинг)

### **Инфраструктура**
- **Хостинг:** Render.com (frontend + backend)
- **База данных:** Supabase (PostgreSQL)
- **CI/CD:** Автодеплой при пуше в main ветку
- **Исходный код:** GitHub
